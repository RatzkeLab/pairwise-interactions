WHAT IS WRONG
-------------
minibar reads column 2 of the barcode TSV as the forward index and column 4 as
the reverse index (its -cols default for a 5-column file is 1,2,3,4,5 =
sample, fwd index, fwd primer, rev index, rev primer).

01_setup/minibar_primers_20260630.tsv puts the WHOLE 59 bp construct in those
columns:

    ATCGCCTACCGTGAC  TCAATCAAGAAGGGAAAGCAAGGT  AGRGTTYGATYMTGGCTCAG
    ^ 15 bp adapter  ^ 24 bp barcode           ^ 20 bp 16S primer
    \___________________ all of this sits in the FwIndex column ___________/

So minibar matches a 59-mer within the barcode edit distance (6) instead of the
24-mer barcode it was meant to match -- the same tolerance spread over 2.5x the
length. Most reads fail and land in unk.fastq.

HOW BAD
-------
Measured on 20260907, which has the identical file layout. On a representative
10,000-read chunk:

    barcode file      -e    assigned    est. false rate
    as generated       6       13.7%              0.15%
    corrected          4       63.6%              1.23%
    corrected          5       67.6%              1.48%

The false rate is measured, not assumed -- 20260907 has 2464 wells that were
barcoded but never PCR'd, so reads landing there are false by construction.
20260630 has no such internal control, so use -e 4 as calibrated there.

20260630's own numbers, consistent with the same problem:
    raw 2,522,561 -> filtered 800,746 (31.7%) -> demultiplexed 119,140
    that is 14.9% of filtered reads assigned, 4.7% of raw.
Expect roughly 3.5-4.5x more reads after the fix.

WHAT THIS CHANGES DOWNSTREAM
----------------------------
Everything built on read depth gets better, nothing gets invalidated: the reads
that were assigned were assigned correctly (the barcodes in the discarded reads
match the sheet at median edit distance 0 -- they were just never matched).
Worth redoing afterwards:
  - 03_recreate_reference_db  : more wells clear the min-reads threshold, so more
                                strains get a corroborated consensus
  - 04_qc                     : two-strain resolution in pair wells is depth
                                limited, so the strain-count estimates improve
  - 05/06                     : relative abundance is a ratio, so it is mostly
                                unchanged, but its variance drops a lot

Do NOT raise -e above 5. The barcode set's minimum pairwise edit distance is 12,
so -e 6 sits exactly on the decision boundary and -e 7+ assigns mostly noise
(measured: 72% false at -e 7).
